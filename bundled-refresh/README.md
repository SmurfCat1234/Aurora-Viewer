# Refreshes for five bundled languages

These optional import files target Aurora Viewer at [`2d505f2b`](https://github.com/Aurora-Viewer/Aurora-Viewer/commit/2d505f2b). They cover Simplified Chinese (`zh-Hans`), Traditional Chinese (`zh-Hant`), Russian (`ru`), German (`de`) and Brazilian Portuguese (`pt-BR`).

Each file contains all 15,193 active message IDs and passed the Fluent render check. These opt-in copies include the release translations and preserve earlier wording revisions for weather, avatar cache, audio, local texture sorting and World filters.

To try a refresh, select **Use a language file (.ftl)** in **Preferences → Language and updates**, choose the file and restart. Keep its original filename. See [PR #4335](https://github.com/Aurora-Viewer/Aurora-Viewer/pull/4335) for the Windows offline captures and review status.
